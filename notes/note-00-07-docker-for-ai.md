## Key Take aways

1. Nvidia Container Toolkit is required if you are on Linux. Its purpose if to bridge device's CUDA drivers with isolated CUDA toolkit inside the container
2. `docker logs` to see the logs
3. `docker cp` to copy files from inside the docker to host machine
4. `docker exec` to execute commands from a running container
5. Docker compose is a tool to manage, start and stop multiple docker containers/services at once
